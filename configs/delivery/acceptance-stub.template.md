# Acceptance stub template

The first fenced block below is the test file that `node scripts/delivery/acceptance.mjs stubs --write`
and `npm run dor -- --write` create for each `- [ ] AC-n: text` of an Increment, at
`acceptance.pattern` in `configs/delivery/delivery.json`. Existing stubs are never rewritten:
they become the real tests, and the Definition of Done requires them implemented.

Placeholders: `{{increment}}` (the Increment id), `{{incrementPath}}` (its path without `.md`),
`{{criterion}}` (`AC-n`), `{{text}}` (the criterion as one comment line), `{{title}}` (the
criterion quoted for a test name). A line holding `{{steps}}` becomes the criterion's
Given/When/Then comments, or disappears when it does not use that form.

```js
// {{increment}} {{criterion}}: acceptance test stub generated by `node scripts/delivery/acceptance.mjs stubs`.
// Replace the pending test with assertions that prove the criterion; this file then is its Evidence.
// Increment: [[{{incrementPath}}]]
// {{criterion}}: {{text}}
// {{steps}}
import test from 'node:test';

test.todo('{{increment}} {{criterion}}: {{title}}');
```
