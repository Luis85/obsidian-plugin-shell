# Companion Visual Editors — implementation handoff baseline

Application-first visual Page and Component editors for Vue 3 / Nuxt UI generation.

## Included
- Page editor for SaaS/enterprise interfaces with website support.
- Reusable Layout library with safe fresh-ID instantiation.
- Component editor with typed Props, Slots, Emits and composite child components.
- Nuxt UI primitive catalog and expandable application recipes.
- Declarative generator IR; no persisted arbitrary JavaScript.
- Project-level validation and implementation-handoff documentation.

Start with `HANDOFF.md`, then `IMPLEMENTATION-READINESS-REVIEW.md`.

The UI files are a high-fidelity interaction reference. Domain/application modules show the intended dependency direction. Sample customer data is illustrative and must not become production domain data.
