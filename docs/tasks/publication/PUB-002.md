# PUB-002 — Rehearse exact companion and template release artifacts

## Outcome
A fixed companion candidate produces independently verifiable runtime assets and proves compatibility with the already qualified framework developer kit without public promotion.

## Baseline and scope
Use the chosen distribution topology and existing [release rehearsal](../../development/RELEASE-REHEARSAL.md) and guarded release operations. Preserve the distinction between installable plugin assets and source archives.

## Acceptance criteria
- [ ] Companion assets and template sources have consistent identities/versions, explicit compatibility and the required licenses/notices.
- [ ] Checksums, provenance, dependency inventory and qualification records identify the exact candidate; no unverified rebuild replaces a tested artifact.
- [ ] Archives exclude credentials, approvals, host profiles, companion-private dependencies in consumer exports and test-only data/providers not intended for production.
- [ ] Clean companion installation and independent template setup/build/generation succeed from the candidate in isolated fixtures.
- [ ] Rehearsal does not create public tags, upload/promote releases or submit directory entries.

## Verification
Run artifact-content, hash/version, independent-consumer and native installation checks. Exercise malformed/incomplete assets and preservation of existing plugin data. Retain all relevant release blockers and actual execution scopes.

## Evidence and handoff
Not executed. Record immutable candidate identifiers, artifacts, exact rehearsal results and remaining limitations. Publication remains PUB-004 with separate explicit authorization.

## Already shipped framework baseline

Reuse the SH-034 kit by exact version/hash; a revised kit must pass its own reopened readiness/shipment gates. This companion rehearsal does not create the first framework distribution and cannot delay that earlier shipment. Retain separate archive/runtime identities and verify the companion plus an independent consumer against the actual compatible kit.
