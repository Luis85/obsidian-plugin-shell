# SH-025 — Deliver the central human and agent CLI

## Outcome
A project-local first-class CLI gives humans and agents one discoverable, stable interface to shell capabilities.

## Baseline and scope
Implement typed parser/command registry, human renderer and machine protocol from shared descriptors. Start with help/status/doctor/config/make/plan, exposing actual availability for later lifecycle handlers. Preserve npm aliases; compiled bootstrap packaging is SH-026.

## Acceptance criteria
- [ ] Direct Node and npm-run routes call identical handlers, including npm silent JSON output; any optional bin delegates to the pinned compatible project version.
- [ ] JSON and no-interaction modes never prompt, including invalid flags/missing inputs; stdout remains one versioned result while child logs/progress go to bounded stderr.
- [ ] Diagnostics and exit semantics are stable; explicit streaming mode has a final result; cancellation/timeouts/partial effects remain truthful.
- [ ] Help/catalog describe input/output schemas, prerequisites, effects, network needs, examples and implementation status; poisoned configuration does not execute during discovery.
- [ ] Status/doctor/root resolution are read-only and do not launch Obsidian, install packages or silently repair projects; yes never bypasses conflicts or trust.

## Verification
Exercise the compiled process under TTY, pipe and CI; capture stdout/stderr/exit status; test cancellation, invalid input, missing roots and legacy alias recursion.

Not executed. Record exact commits/artifacts, commands/results, environment and remaining scope. Documentation is not implementation evidence or execution authorization.
