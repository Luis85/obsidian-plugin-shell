# SH-017 — Compile a design into a reviewed source plan

## Outcome
A standalone CLI compiles a bounded design scope into existing maker operations with explicit support and implementation obligations.

## Baseline and scope
Combine versioned catalog, design schema, makers and source ports. Implement validation, dependency closure, normalized intermediate representation and deterministic planning. Include an action contract for trigger/input/validation/operation/success/failure/feedback rather than infer behavior from button captions.

## Acceptance criteria
- [ ] Selected valid features compile even when unrelated drafts remain incomplete; required references are included or reported.
- [ ] Identity, containers, screens, entities, components, actions and source usages map to explicit supported output.
- [ ] Every selected element is classified supported scaffold, contract only, manual work or blocked; nothing is silently omitted.
- [ ] Layout/selection changes leave semantic output unchanged; incompatible template/protocol versions fail before mutation.
- [ ] A future UI can consume the identical plan contract without another compiler implementation.

## Verification
Test deterministic plans, malformed input, unsupported mappings, dependency cycles, separate DTO/entity mappings, native registration counts and two consumer designs. Compile representative outputs rather than rely only on snapshots.

## Evidence and handoff
Not executed. Record supported subset, compiler/catalog versions, generated outputs and actual tests. Installation and ownership-aware apply remain shared operation responsibilities.
