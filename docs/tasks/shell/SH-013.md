# SH-013 — Export an independent shell template

## Outcome
A developer receives a clean standalone source artifact containing everything needed to develop without the companion or maintainer workspace.

## Baseline and scope
Inspect setup, example removal, release rehearsal and public feature APIs. Specify an explicit export manifest with source, scripts, lockfile, tests, relevant docs and licenses. Separate an internal qualified source artifact from public release assets; do not rename the root plugin now.

## Acceptance criteria
- [ ] Export contains the supported standalone CLI/runtime and a data-only version/capability manifest.
- [ ] It excludes companion implementation/concept assets, credentials, approvals, host profiles, node_modules and maintainer-only state.
- [ ] A Git-free extracted consumer installs/builds/checks independently with no unpublished workspace or absolute-path dependency.
- [ ] Minimal and example-enabled profiles preserve shared tests and safe example removal; repeated export is reproducible under declared inputs.

## Verification
Inspect archive paths/contents, licenses and import graphs; run independent setup, feature generation and verification outside the maintainer tree. Record distribution/policy risks for later PUB-001 without executing publication.
