# CP-003 — Integrate the native design editors

## Outcome
The accepted requirements, sitemap, entity, component and source editors operate on real project records inside the shell-based companion.

## Baseline and scope
Port the CX-007 feature scope and CX-003 interaction contracts to actual Vue components, typed composables/stores and shared application services. Retain the [editor review](../../concepts/companion/EDITORS-REVIEW.md) as regression input, not proof that the native port works.

## Acceptance criteria
- [ ] Each selected editor reads and commits through canonical records, with explicit draft validation and used-by/impact inspection.
- [ ] Outline, canvas and inspector selection agree; containment, navigation, entity relationships and data flows remain distinct.
- [ ] Creating a screen inside a container, connecting a source, editing/removing a relationship and changing inspector context preserve the accepted behavior.
- [ ] No-op and viewport changes do not mutate semantic generation state or destroy Redo; guarded deletion cannot orphan references.
- [ ] Keyboard and non-drag routes, focus restoration, narrow leaves, supported pop-outs and theme inheritance work without global event/style ownership leaks.

## Verification
Exercise real components and services in the harness, then named native interaction/restart cases. Compare against the accepted concept scenarios; record deliberate differences and unported features rather than hide them.

## Evidence and handoff
Not executed. Record concept/foundation/native revisions, actual regression results and accessibility gaps. Broader declared-scale qualification remains CP-009.

and [browser polishing scope](../../concepts/companion/DETAIL-EDITORS-POLISH.md)
into the port. Their browser implementation does not check these native boxes.

- [ ] Derive typed scalar controls from component contracts; preserve false, zero,
  empty text, local overrides and invalid draft input. Definition/version changes

- [ ] Keep page/structure search, ancestry, direct usage and return context coherent
  across real native leaves without persisting transient queries or stale findings.
- [ ] Provide advisory targeted Review findings and ancestor-aware state summaries
  with explicit count scope. Never convert their absence into an executed-test verdict.

  an explicit implementation boundary, through the shell's document/export services.

  coarse pointers and both host themes with actual interactions and assistive tools.

  mapping, component revision history and interaction-to-test lowering separately.
