# CX-008 — Project Starters

Status: Implemented concept and generator integration; qualification evidence is scoped separately.

## Outcome

A developer chooses a curated project JSON or Start Blank, configures identity/folders, reviews replacement safely, exports it and generates an independent runnable plugin shell. The companion remains a concept; no native write/installation/publication is implied.

## Implementation

- Original nine-entry built-in catalog with full project-v4 files and integrity metadata.
- Search/category gallery, included/remaining-scope preview, protected configuration and existing atomic import review.
- Normal JSON export plus actual plan/hash/apply generator handoff.
- Companion self-project updated with the catalog surface, detailed page and acceptance requirement.
- Exact asset inventory, all-starter negative/round-trip/plan/apply checks, browser interaction/safety checks and per-starter generated install/build/type-check/test workflow.

## Acceptance boundary

A valid JSON or green scaffold test is not acceptance of native persistence, editor integration, live source access, task recurrence, indexing, OAuth, file parsing, screen-reader conformance or plugin publication. These remain explicit tasks in the generated project and companion conversion.
