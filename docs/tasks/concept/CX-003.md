# CX-003 — Unify editor interactions and retain regressions

## Outcome
Sitemap, entity and data-source editors use coherent selection, drafts and relationship operations while feature design continues.

## Baseline and scope
Review current source and [EDITORS-REVIEW.md](../../concepts/companion/EDITORS-REVIEW.md) before treating earlier reported defects as unresolved. Preserve view-container/internal-screen distinctions, source targeting, relationship removal and inspector-context corrections.

## Acceptance criteria
- [ ] Outline, canvas and inspector agree on one selected object and valid contextual actions; switching context preserves or explicitly resolves drafts.
- [ ] Containment/navigation/entity/data edges retain distinct semantics and usable labels; editing/removing one never silently changes another kind.
- [ ] Connect/reparent/position/remove have non-drag and keyboard paths, with visible focus and reliable target selection.
- [ ] No-op operations preserve Redo; layout and selection do not change semantic generation readiness.

## Verification
Run retained exact-artifact regressions plus scenario tests for creating a screen in a container, connecting a source, deleting a relationship and switching inspector context. Distinguish pointer tests from controlled model tests; document dense-graph limitations.

## Evidence and handoff
Not executed. Record actual corrected gaps, protected behaviors and remaining UX questions. Native host and performance qualification remain separate.
