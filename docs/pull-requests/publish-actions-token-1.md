# Let Publish run with the built-in Actions token

## Summary

Publish probes GET /user only when the repository reports push: false; an installation token (HTTP 403) leaves the permission unknown so the job grants decide, while a user token without push access is still refused before any write. Delivers AC-1 and AC-2.

## Scope

### In scope

- The `GET /user` token probe in `tooling/release/publish-github.mjs` and the push-permission decision in `tooling/release/publish-discovery.mjs`.
- The fake remote's `GET /user` route, the client and refusal tests, the AC-1 and AC-2 acceptance tests, the publish guide and the Unreleased entry.

### Out of scope

- Re-dispatching Publish for 0.5.0, `RELEASE_TOKEN` handling and the workflows.
