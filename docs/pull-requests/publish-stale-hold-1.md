# Re-run the stale release-PR CI hold in Publish

## Summary

Publish discovers a stale failed "CI result" from the release pull request's own ci.yml run and, once Release result is green, re-runs its failed jobs in a new requalify step before merging, waiting within a bounded budget. Delivers AC-1, AC-2 and AC-3.

## Scope

### In scope

- Stale-hold discovery, the `requalify` step with its bounded wait, `actions: write` on the publish job and the corrected `ci.yml` comment.
- Fake-remote support, unit and acceptance tests, the publish guide, the workflow reference and the Unreleased entry.

### Out of scope

- What the hold checks, the Release workflow and `RELEASE_TOKEN` handling.

- [x] T-4: Cover discovery, the step, refusal, timeout and resume with the fake remote and acceptance tests
