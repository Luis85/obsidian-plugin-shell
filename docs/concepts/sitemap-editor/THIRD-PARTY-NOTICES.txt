Requested-stack source dependencies
-----------------------------------
Vue, Vue Router, Nuxt UI, Vue Flow, Vite, Tailwind CSS, the single-file Vite
plugin, and Iconify/Lucide assets are referenced through package.json.
Package implementations are not vendored in this source delivery. Install
and review the license files shipped with each resolved package. Nuxt UI
uses several additional transitive dependencies; preserve their license
notices when distributing a compiled application.

No font files are included. Editor typography uses system fonts.
