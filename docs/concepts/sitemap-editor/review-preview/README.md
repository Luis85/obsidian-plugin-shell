# Offline layout review

`editor-only-review.html` is an embedded-asset, vanilla-JavaScript preview of the shell-free layout. **It does not run Vue, Nuxt UI, or Vue Flow.** The real requested-stack source is in `../src` and has not been compiled or browser-verified in this delivery because registry access was blocked.

Use this file only to inspect the layout and contextual navigation immediately. Its About dialog identifies the runtime. For build instructions, verification status, and behavior differences between the two renderers, read the root README.
