# Example data

All note content in these examples is synthetic. No real vault was read to create them.

- `inbox-routing.prompt.json`: editable recipe generated by the actual domain factory.
- `starter-library.json`: four editable templates. Importing creates independent copies.
- `inbox-routing.demo-request.json`: official request shape compiled from the synthetic demo vault; includes demo note bodies and paths.
- `inbox-routing.synthetic-response.json`: **fabricated fixture**, not a Jev response from a live call; use it only to inspect the test-bench flow.
- `edited-roundtrip.prompt.json`: recipe downloaded by the browser interaction test after editing the title and first rubric.

Regenerate the first four with `node scripts/export-examples.cjs`; the browser suite regenerates the fifth. Validate the recipe/library/request documents with `python tests/schema.test.py`.
