## Review without unnecessary feature expansion

Architecture review retained the framework-free domain/application ports, composition-only main, runtime-scoped bus, per-view Pinia and Markdown canonical storage. No second Task database or global singleton was introduced. Existing validation, collision, stale-plan, corrupt/future settings and concurrent-write tests remain intact. Optional open/notice failures remain independent of mutation success. Source-size/locale/token, host CSS containment and artifact identity gates remain blocking.

The Obsidian review covers startup, native declarative settings, command/ribbon/menu routes, direct-child header targeting, listener cleanup, moved and restored leaves, actual modal dismissal and preserving unrelated Markdown controls. The native test records its installed asset hashes before exercising behavior, then compares them after cold process restart. Test-only native APIs are not included in the shipped plugin.

Vue/Nuxt review retains scoped Teleport ownership, local icons, per-view DOM IDs, independent caught-error observation, host light/dark inheritance and the source-hash guards. UX review focuses on layout, long/translated labels, form states, empty preview, explicit create, error placement, focus and restoration—not replacing the product with a new dashboard. Browser assertions use actual services/serializer and compare outside-root controls; screenshots are supplemental, not the sole oracle.

Security/privacy review found no HTML rendering of user Markdown, outbound application network dependency or private-path diagnostic payload. This is a bounded code review, not a proof that no security defects exist. Build/install only target approved contained vaults, never publish, and retain notices. Final evidence excludes fonts, native/browser executables and vault content. CI uses read-only repository tokens in retained qualification workflows; temporary recovery and dependency-investigation workflows are removed before the final candidate.
