## Summary

`## [Unreleased]` in `CHANGELOG.md` is empty although development dependencies were updated after the 0.6.0 cut, and Release cut refuses an empty Unreleased section. Add one `### Changed` entry that lists the merged dependency updates so the next patch release can be cut.

## Outcome

`CHANGELOG.md` lists the merged development dependency updates under `## [Unreleased]` › `### Changed`, `node src/cli/tooling/release/changelog.mjs check` passes, and a maintainer can preview a patch release cut.

## Scope

### In scope

- One `### Changed` entry under `## [Unreleased]` naming the updated development dependencies (Vue, Vite, Tailwind CSS, Playwright, Astro, oxlint, typescript-eslint, Prettier, happy-dom, `@iconify-json/lucide`) and stating that behavior does not change.
- One acceptance test that pins where the entry lives.

### Out of scope

- The dependency updates themselves, which merged earlier as separate Dependabot pull requests.
- Dependabot updates that are still open; the entry lists only merged ones.
- Cutting, tagging or publishing a release, which needs a separate explicit owner decision.
- Any change to the release tooling or the delivery rules.
