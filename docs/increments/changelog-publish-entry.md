# Move the Publish token fix back to Unreleased

<!-- Developer handoff for one pull request. `npm run dor` checks it before implementation,
`npm run dod` after it. Replace every <placeholder>; delete these comments when done. -->

## Summary

Publishing 0.5.0 merged `release/0.5.0` into `main`, and Git placed `main`'s newer Unreleased entry "Publish no longer refuses the built-in `GITHUB_TOKEN` …" (from the `publish-actions-token` increment, merged after the 0.5.0 cut) inside `## [0.5.0] › ### Fixed`. That fix is not part of the 0.5.0 tag (`4617944`); the published release notes are correct, only `main`'s `CHANGELOG.md` misattributes it. Move the line back under `## [Unreleased] › ### Fixed`.

## Outcome

`CHANGELOG.md` on `main` lists the Publish `GITHUB_TOKEN` fix under Unreleased for the next release, and its `[0.5.0]` section again matches the notes of the published 0.5.0 release.

## Scope

### In scope

- Move the one changelog entry from `[0.5.0] › Fixed` to `[Unreleased] › Fixed` in `CHANGELOG.md`.
- One acceptance test that pins where the entry lives.

### Out of scope

- Other changelog wording, the published 0.5.0 release and its notes, and the release tooling.
