## Summary

Extend the existing increment documents with a planning commitment, review presentation and unfinished-item carry-over, building on pull request 103.

## Outcome

A planning discussion becomes a scoped iteration with a dedicated branch and optional draft pull request. Reviewers see delivered work and unfinished issues can enter the next plan without losing history.

## Scope

### In scope

- Planning and commitment through reviewed CLI plans, configurable document folders, issue references, and iteration branch enforcement
- GitHub and Azure review, close and merge operations with explicit reviewed approval
- Review presentation and carry-over with preserved source records

### Out of scope

- Plugin runtime screens and hosted meeting services
- Release publication and automatic review approval
