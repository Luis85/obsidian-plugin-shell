## Rationale

The retained rule "maintain exact tested stable dependencies through reviewed updates" (repository instructions) and MVP-21/MVP-23 already imply exact pins, but no PBI makes them a publication precondition. Today `scripts/security/check-dependencies.mjs` checks only the framework root `dependencies`/`devDependencies` against the lockfile and installed modules. It does not cover generated consumers, starter packs, optional workspaces or `overrides`, and it is not bound to publication.

## Impact

- Adds four acceptance criteria. Progress denominators become 55 PBIs and 220 criteria; nothing is accepted by this change.
- No existing PBI revision, status, dependency or acceptance changes. Whether WB-PBI-045 should depend on WB-PBI-055 is recorded as an open question, to be decided in that PBI's next revision.
- No runtime gate, task status, release approval or dependency version changes.
